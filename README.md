# Active Pen Company — ABC Costing Simulation

An interactive classroom simulation covering Activity-Based Costing (ABC),
built for MBA/PGDM coursework.

## For students

Just open this page and follow the on-screen instructions:
1. Log in with your name and official roll number.
2. Read the consent notice and check the required box to proceed.
3. Work through the phases in order — each phase is checked automatically
   before you can move on.
4. You have a limited number of attempts, so read carefully before
   submitting.

If you hit a technical issue (not a "your answer is wrong" message, but an
actual error or the page failing to load), contact your instructor rather
than trying to work around it.

## For instructors

This is the student-facing static page only. Grading logic, source data
generation, and scoring rubrics are maintained separately and are not part
of this repository, by design — publishing the answer-derivation logic
alongside the assignment would let it be reverse-engineered.

If you're an instructor looking to adapt or extend this simulation, please
get in touch with whoever maintains the deployment for access to the full
source and documentation.
